# RPG games

Welcome to my portfolio of text-based RPG games built with Python. This repository serves as a centralized hub for my practice projects, showcasing my journey in conditional programming logic and code organization.

## 📌 Project Overview
All projects inside this repository are **purely text-based CLI adventures** focused on choice-driven mechanics (`if/elif/else`), state management, and core programming logic. These are quick, 5-minute micro-RPGs with dark atmospheres and minimal storylines, built purely for coding practice.

> **Refactoring Note:** 
> Previously, these projects were scattered across separate single-file repositories. To improve my codebase organization, I consolidated all these standalone practice games into this single, clean ecosystem.

---

## 🎮 List of Games Included
*This list will expand as I develop and add new projects.*

*   **[ShadowRPG](./ShadowRPG.py)** — A grim role-playing game with multiple forks and one bad end.
*   **[my_game](./my_game.py)** — A role-playing game without a plot, based on choices and the 'if/else/elif` construction.
*   **[test_pygame](./test_pygame.py)** — A script test of the Pygame library with almost no graphics.

---

## 🛠️ Environment & Requirements
*   **Language:** Python 3.13.13
*   **Environment:** These scripts do not have compiled executable files. They are pure source code designed to run directly in Python environments like **IDLE**, **Pydroid**, or **Acode**.
*   **External Libraries:** Some projects require third-party packages to run correctly.

### How to Run
1. Download or clone this repository to your device.
2. Open the desired file (`ShadowRPG.py`, `my_game.py`, or `test_pygame.py`) in your preferred Python IDE (**IDLE** on PC, or **Pydroid** / **Acode** on mobile).
3. Run the script directly through the built-in terminal or interpreter.
